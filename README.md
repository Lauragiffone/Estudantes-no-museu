# OBJETIVO
Projeto piloto - "Hello Word" - destinado ao aperfeiçoamento das respectivas linguagens utilizadas em seu desenvolvimento; a escolha da criação do Web site do Projeto Estudantes nos Museus deriva do desejo de fomentar veiculação informações sobre os circuitos, percursos educativos, conteúdos culturais, bem como interlocução de estudantes, professores, coordenadores e diretores, haja vista que o mesmo oportuniza ocupação dos estudantes de colégios estaduais do governo do estado e utilização do patrimônio museológico como suporte essencial no processo educativo que contribui para a construção de uma cultura cidadã e para o desenvolvimento sociocultural desses alunos.
